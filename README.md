# 🫁 ANIMA

> AI 기반 개인 맞춤형 기침 음향 패턴 기록 시스템  
> A Normal-Distribution-Based System for Recording Changes in Personalized Cough Acoustic Patterns

<br>

## 📌 프로젝트 소개

**ANIMA**는 사용자의 기침 소리를 분석하여  
개인별 기침 음향 패턴의 변화를 기록하고 확인할 수 있도록 설계한  
AI 기반 헬스케어 프로젝트입니다.

기존의 기침 관리는 설문지, 사용자의 기억, 주관적인 증상 기록에 의존하는 경우가 많습니다.  
이러한 방식은 복약 전후의 변화, 생활 환경에 따른 악화 여부, 장기적인 증상 추이를  
객관적으로 비교하기 어렵다는 한계가 있습니다.

ANIMA는 이러한 문제를 보완하기 위해 사용자가 녹음한 기침 음성을 분석하고,  
기침 여부와 음성 품질, 정상 기준 분포 대비 이탈 정도를 함께 기록합니다.  
이를 통해 사용자는 자신의 기침 패턴이 시간에 따라 어떻게 변화하는지  
날짜별 기록과 그래프를 통해 확인할 수 있습니다.

<br>

## 🎯 프로젝트 목적

ANIMA의 목적은 단순히 기침이 발생했는지 확인하는 것이 아니라,  
사용자의 기침 음향 패턴을 지속적으로 기록하고 변화 추이를 정량적으로 확인하는 것입니다.

이를 통해 다음과 같은 목표를 달성하고자 합니다.

- 사용자의 기침 음성 데이터를 체계적으로 기록
- AI 기반으로 기침 여부와 분석 신뢰도 확인
- 건강한 기침 기준 분포와 비교하여 이탈도 점수 계산
- 날짜별, 시간별 기침 기록 저장
- 장기적인 기침 패턴 변화 시각화
- 향후 비대면 진료 및 호흡기 건강 모니터링 보조 도구로 확장

<br>

## 🧠 핵심 아이디어

ANIMA는 사용자가 녹음한 기침 음성을 서버로 전송한 뒤,  
음성 데이터를 표준화하고 AI 분석 과정을 거쳐 기침 여부를 판별합니다.

분석 과정에서는 STFT와 Spectrogram 기반 특징을 활용하여  
기침 음성의 시간-주파수 특성을 추출합니다.  
이후 기침으로 판단된 음성은 건강한 기침 기준 분포와 비교되며,  
마할라노비스 거리 기반 이탈도 점수를 통해 정상 기준에서 얼마나 벗어났는지를 계산합니다.

즉, ANIMA는 단순한 기침 감지 시스템이 아니라  
사용자의 기침 패턴 변화 자체를 기록하고 관리하는 시스템입니다.

<br>

## ⚙️ 주요 기능

| 기능 | 설명 |
|---|---|
| 기침 음성 녹음 | 사용자가 모바일 앱을 통해 기침 소리를 녹음 |
| 음성 전처리 | 입력 음성을 16kHz mono 형식으로 표준화 |
| 품질 점수 계산 | 녹음 길이, 잡음, 클리핑 여부 등을 바탕으로 음성 품질 평가 |
| 기침 여부 판별 | AI 모델을 이용해 입력 음성이 기침인지 분석 |
| 이탈도 분석 | 건강 기침 기준 분포와 비교하여 마할라노비스 거리 계산 |
| 기록 저장 | 분석 결과, 사용자 입력, 환경 정보를 DB에 저장 |
| 히스토리 조회 | 날짜별 기침 기록과 월별 변화 그래프 확인 |
| 웨어러블 확장 | 향후 웨어러블 기기와 연동하여 기침 의심 이벤트 감지 |

## 🏗️ 시스템 구조

ANIMA는 다음과 같은 구성 요소로 설계되었습니다.

사용자
  ↓
모바일 앱
  ↓
AI 분석 서버
  ↓
음성 전처리 및 특징 추출
  ↓
기침 여부 판별
  ↓
정상 기준 분포 비교
  ↓
이탈도 점수 계산
  ↓
분석 결과 저장 및 시각화
````

<br>

## 🔍 분석 흐름

1. 사용자가 모바일 앱에서 기침 음성을 녹음합니다.
2. 녹음된 음성은 서버로 업로드됩니다.
3. 서버는 음성을 16kHz mono 형식으로 표준화합니다.
4. 잡음, 길이, 클리핑 여부 등을 확인하여 품질 점수를 계산합니다.
5. STFT/Spectrogram 기반 특징을 추출합니다.
6. AI 모델을 통해 기침 여부와 분석 신뢰도를 계산합니다.
7. 기침으로 판단된 음성은 건강 기침 기준 분포와 비교됩니다.
8. 마할라노비스 거리를 이용해 이탈도 점수를 산출합니다.
9. 분석 결과는 사용자 기록으로 저장됩니다.
10. 사용자는 앱에서 날짜별 기록과 그래프를 확인할 수 있습니다.

## 📊 기대 효과

ANIMA가 완성될 경우 사용자는 자신의 기침 상태를 보다 객관적으로 확인할 수 있습니다.
또한 의료진에게 기침 패턴 변화 기록을 제공하여 진료 보조 자료로 활용할 수 있으며,
요양 시설이나 독거노인 등 지속적인 관찰이 필요한 환경에서도
호흡기 건강 모니터링 도구로 확장될 수 있습니다.

장기적으로는 한국인 기침 음향 데이터를 축적하여
국내 호흡기 건강 연구를 위한 기초 데이터셋 구축에도 기여할 수 있습니다.
